### The landscape of Data Quality Issues

_2026-07-17_

**Taught**

The 6 core dimensions of data quality issues; 1. Completeness (Do i have all the values I should have?)
2. Uniqueness (Does each real-world thing appear exactly once, correctly?
3. Validity (Is each value actually a legal value for it field?)
4. Consistency (Do values agree with each other, within and across systems?)
5. Accuracy (Is each value close to the true, real-world value?)
6. Timeless (Is the value current enough, and dated correctly, to be trusted?)

**What I now understand**

I will repeatedly go through this dimensions with practicals as often as possible to familiarise.
